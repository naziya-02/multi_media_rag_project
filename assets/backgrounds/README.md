# Decorative background images

The app uses two locally stored decorative images when present:

- `hero-abstract.jpg` — [Unsplash abstract technology backgrounds](https://unsplash.com/s/photos/abstract-technology-background), photo `1634017839464-5c339ebe3cb4`, served through `images.unsplash.com`.
- `landing-dark.jpg` — [Unsplash dark purple abstract backgrounds](https://unsplash.com/s/photos/dark-purple-abstract), photo `1557682250-33bd709cbe85`, served through `images.unsplash.com`.

Both are downloaded from Unsplash and are made available under the [Unsplash License](https://unsplash.com/license); photographer attribution is not required by that license, but the source pages and photo IDs are recorded here. The Pexels recruitment search was also reviewed as requested; it was not selected because its featured result was a recruitment sign rather than a suitable abstract background. If images are missing, the UI falls back to layered dark gradients. Images are decorative, overlaid for contrast, and never contain essential content.
